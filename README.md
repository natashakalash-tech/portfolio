# Портфолио — Наталья Кэ

Одностраничный лендинг-портфолио: вайб-кодинг, Telegram-боты, вёрстка, API и AI.

## Технологии

- HTML5
- CSS3 (адаптивная вёрстка, CSS-переменные)
- JavaScript (мобильное меню)

## Структура проекта

| Файл | Назначение |
|------|------------|
| `index.html` | разметка и текст сайта |
| `style.css` | стили и яркость фона |
| `script.js` | меню на телефоне |
| `background.jpeg` | фоновое изображение |

## Локальный запуск

1. Откройте папку в Cursor или VS Code.
2. Установите расширение **Live Server**.
3. Правый клик по `index.html` → **Open with Live Server**.

Или откройте `index.html` двойным щелчком в браузере.
